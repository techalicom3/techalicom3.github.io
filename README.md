# Tech Ali - Mobile Accessories Store

Pages: index.html, products.html, product-details.html, cart.html, checkout.html, order-success.html, about.html, contact.html.

Products are maintained in `product-data.js` with real product/model names matched to the uploaded photos. Prices were refreshed against Pakistan-market listings checked in September 2026; prices can change by seller, stock, authenticity and warranty.

Product categories are limited to the products actually present: Chargers, Cables, TWS Earbuds, Headphones, Wired Earphones, Neckbands, Smartwatches and Phone Cases. There is no Tools category.

Checkout saves orders into the Supabase `orders` table. WhatsApp remains only as a support link; product cards use VIEW DETAILS and ADD TO CART, while product details use ADD TO CART and BUY NOW.
